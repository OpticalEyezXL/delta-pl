# delta-pl

Verification scripts for the *dissipative-projection* paper (physical_law /
[PL]) by Optical Eyez XL — the classical-field consequences of the single
self-adjoint dissipative generator Δeₙ=n²eₙ established in the companion
paper *Preservation of Distinguishability*.

Korean-commented originals and English translations are both included.

## Contents

| File | Description |
|---|---|
| `physical_law_verification.py` / `physical_law_verification_en.py` | Verifies: T1/T2 (time integral of the dissipative semigroup and the d=3 Newtonian/Coulombic Green's function), Sec. 6.2 (Delta-sign check for the Navier-Stokes equation and re-derivation of the Taylor-Green pressure solution — including confirmation that the previous pressure solution was in error), Sec. 3.1 (magnitude/phase separation of V_mn(t) into real-axis envelope and imaginary-axis phase), Sec. 10 (relaxation-decoherence inequality, exhaustively checked over 2450 mode pairs), Appendix K / T7 (many-body gravity as Green's-function superposition, verified via a convergence-checked finite-difference Laplacian), Sec. 5.4 (the displacement current forced algebraically by T3 and charge conservation), and, as an **incidental exploration using standard energy methods** (not derived from the Delta structure itself), the energy-neutrality of the triple-coupling tensor generated by the advection term (Sec. 6 addendum). |

## How to Run

```bash
pip install mpmath numpy sympy
python physical_law_verification_en.py
```

All assertions in the script correspond to numerical claims made in the
paper; a clean run (no `AssertionError`) reproduces every reported result.
