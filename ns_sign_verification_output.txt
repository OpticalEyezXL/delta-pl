=== 1. 비압축성 확인 (∇·u = 0) ===
div u: 0

=== 2. NS 방정식(Δ 부호: -ηΔu, 즉 표준 +η∇²u와 동치)에서 요구되는 ∇p ===
필요한 ∂p/∂x: rho*exp(-4*eta*t/rho)*sin(2*x)/2
필요한 ∂p/∂y: rho*exp(-4*eta*t/rho)*sin(2*y)/2

=== 3. 문서의 압력해 검증: p = -(ρ/4)(cos2x+cos2y) e^{-4ηt/ρ} ===
dp/dx 잔차 (0이어야 함): 0
dp/dy 잔차 (0이어야 함): 0
-> 확인됨: 위 압력장이 정확히 해석해다.

=== 4. 이전 판(오류)이었던 p = (ρ/4)(cos2x - cos2y) 검증 ===
dp/dx 잔차: -rho*sin(2*x)/2 - rho*exp(-4*eta*t/rho)*sin(2*x)/2
dp/dy 잔차: rho*sin(2*y)/2 - rho*exp(-4*eta*t/rho)*sin(2*y)/2
-> 0이 아님: 부호·항·시간감쇠 인자 모두 틀렸던 것으로 확인됨.

=== 5. 압력 포아송 방정식 부호: 연산자 항등식 + Taylor-Green 실계산으로 확인 ===
연산자 교환 항등식 잔차 (0이어야 함): 0

따라서 NS 방정식 rho(u_t+(u.grad)u) = -grad p + eta*Laplacian(u) (= -eta*Delta u)에
발산을 취하면:
  좌변: rho*d/dt(div u) + rho*div[(u.grad)u] = rho*div[(u.grad)u]   (div u = 0)
  우변: -Laplacian(p) + eta*Laplacian(div u) = -Laplacian(p)        (div u = 0, 위 교환 항등식)
=> Laplacian(p) = -rho*div[(u.grad)u]
=> Delta(p) = rho*div[(u.grad)u]   (Delta = -Laplacian 관례)

이 부호(+rho)는 위 3번 단계에서 Taylor-Green 압력해를 실제로 검증함으로써
독립적으로 재확인된다(그 압력해 자체가 이 Delta(p)=rho*div[...] 조건으로부터
∂p/∂x, ∂p/∂y를 직접 적분해 얻어졌기 때문).
